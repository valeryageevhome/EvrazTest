## ⚡ Ключевой функционал

* 🔍 **Справочная валидация (White-list):** считывает справочники шахт и марок угля из `Справочники.xlsx`. Все неучтенные позиции автоматически отсекаются.
* 📂 **Парсинг и консолидация:** обходит структуру каталогов, извлекает данные из отчетов вида `<Шахта>_ОТЧЕТ.xlsx`.
* 📈 **Двухуровневая агрегация:** группирует сводную таблицу по связке **Шахта ➔ Марка ➔ Вес**, рассчитывает суммарный объем отгрузок и округляет значения до сотых.
* 🌐 **Интеграция с ФНС ЕГРЮЛ:** через web-интерфейс [egrul.nalog.ru](https://egrul.nalog.ru/index.html) находит компании по ИНН, скачивает актуальные PDF-выписки и раскладывает их по целевым папкам шахт.
* 🛡️ **Отказоустойчивость:** архитектура на базе машины состояний (State Machine) с обработкой бизнес- и системных исключений (`Try-Catch`), подробным логированием и автоформатированием Excel.
