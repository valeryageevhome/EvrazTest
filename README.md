# 🤖 Primo RPA: Консолидация отчетов по отгрузке угля и выгрузка выписок ЕГРЮЛ

## 📌 Основные задачи робота

1. **Валидация по справочникам:** считывание разрешенного списка шахт и марок угля из `Справочники.xlsx` (листы *«Шахты»* и *«Марка»*). Неучтенные данные отсекаются.
2. **Парсинг и консолидация:** обход структуры папок, чтение персональных отчетов шахт вида `<Шахта>_ОТЧЕТ.xlsx` и сбор данных по отгрузкам.
3. **Группировка и расчет:** сведение данных в итоговый файл с двухуровневой группировкой (**Шахта ➔ Марка ➔ Вес**), суммированием веса и округлением до 2 знаков после запятой.
4. **Интеграция с ЕГРЮЛ (ФНС):** автоматический поиск по ИНН на портале [egrul.nalog.ru](https://egrul.nalog.ru/index.html), скачивание актуальной PDF-выписки и сохранение в папку соответствующей шахты.
5. **Логирование и безопасность:** обработка исключений в блоках `Try-Catch`, автоподбор ширины колонок и фиксация шагов в лог.

## 🛠 Системные требования

* **ОС:** Windows 10 / 11
* **ПО:** Primo RPA Studio Community (режим запуска **Pro**)
* **Браузер:** Google Chrome
* **Расширение:** установленное и включенное расширение **Primo RPA v3** для соответствующего браузера

## ⚙️ Конфигурация (`Settings / Config.xlsx`)

Перед запуском убедитесь, что в конфигурационном файле заданы корректные пути:

| Параметр | Описание | Пример значения |
| :--- | :--- | :--- |
| `RootFolderPath` | Корневая директория с папками шахт | `C:\RPA\Шахты\` |
| `DirectoryDictPath` | Путь к файлу справочников | `C:\RPA\Справочники.xlsx` |
| `EgrulUrl` | Ссылка на сервис ФНС ЕГРЮЛ | `https://egrul.nalog.ru/index.html` |
| `ErrorFolderPath` | Каталог для логов/скриншотов ошибок | `C:\RPA\Errors\` |
| `ResultFilePath` | Путь к итоговому файлу отчета | `C:\RPA\Результат.xlsx` |

> ⚠️ **Важное замечание по загрузкам браузера:**  
> В процессе работы робот настраивает каталог скачивания на `C:\RPA_Downloads`. При необходимости после выполнения сценария верните привычный путь загрузок в настройках браузера.

## 🚀 Порядок запуска

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/valeryageevhome/EvrazTest.git
   ```
2. Откройте проект в **Primo RPA Studio** (файл проекта в папке `TestProject`).
3. Проверьте актуальность путей в конфигурационном файле.
4. Убедитесь, что расширение браузера **Primo RPA v3** активно.
5. Запустите главный процесс `MainProcess.ltw` (или `Main.ltw`).
